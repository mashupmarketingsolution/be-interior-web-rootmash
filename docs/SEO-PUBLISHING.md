# Publishing with SEO

Blog, Home Project and Office Project editors now include a collapsed SEO (optional) section. Existing posts need no migration.

Leave fields empty to use the post title, automatic description and cover image. Override only when a more specific title or summary helps readers. Length warnings are suggestions and do not block publishing. Social image defaults to the post cover.

Keep Hide this page from search engines off for normal public posts. Turning it on emits noindex and removes that entry from the sitemap after refresh (up to one hour plus upstream caching). It is not a privacy control. Search engines must recrawl to reflect changes.

Publish actual project facts and original photos. Static service pages retain their built-in metadata.

After deployment: verify the domain in Google Search Console, submit /sitemap.xml, inspect representative URLs and review indexing. Business Profile setup requires access to the business account. Neither account verification nor production deployment is completed by this code change.
